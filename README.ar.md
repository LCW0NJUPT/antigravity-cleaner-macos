## 🌍 المشكلة العالمية التي نحلها

تم تطوير **Antigravity Cleaner** في الأصل للمستخدمين في إيران، لكن المشاكل التي يحلها **عالمية**.

### 🎯 المشاكل التي نحلها:

- **🚫 القيود الإقليمية**: خدمات Google محظورة (إيران، كوبا، سوريا، كوريا الشمالية)
- **🌐 تداخل الشبكة**: التلاعب بـ DNS، تعارضات البروكسي
- **🔒 قفل المنطقة**: رسالة "غير متاح في منطقتك"
- **📡 مشاكل الاتصال**: أخطاء الشبكة، انتهاء المهلة، SSL
- **🔄 أخطاء التثبيت**: التنزيلات التالفة، العمليات العالقة

## 🚀 التثبيت بأمر واحد

### 🪟 Windows (PowerShell)
```powershell
iwr -useb https://raw.githubusercontent.com/LCW0NJUPT/antigravity-cleaner-macos/main/install.ps1 | iex
```

### 🍎 macOS / 🐧 Linux
```bash
curl -sL https://raw.githubusercontent.com/LCW0NJUPT/antigravity-cleaner-macos/main/install.sh | bash
```

## ✨ الميزات الرئيسية

### 🧹 التنظيف العميق
- إزالة الآثار من AppData والسجل وإضافات Chrome
- نسخ احتياطي تلقائي قبل الحذف

### 🌐 إعادة تعيين الشبكة
- تنفيذ `netsh` و `flushdns`
- إصلاح أخطاء الشبكة وقفل المنطقة

### 🌐 مساعد تسجيل الدخول (v2.1+)
- تنظيف بيانات Antigravity فقط
- دعم Chrome، Edge، Brave، Firefox
- تخزين مشفر (AES-256)

### 7️⃣ مدير الجلسات
- نسخ احتياطي واستعادة الجلسات
- تشفير AES-256-GCM
- انتهاء صلاحية 30 يوماً
